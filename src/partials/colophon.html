Zero JavaScript

This page is one HTML file and one stylesheet. There is no script element, no event handler and no JavaScript URL, and the build fails if one ever appears. Node and Sass are used only to build it.

How it moves

The console is a set of radio buttons. :has() on the page root turns the checked ones into a handful of typed custom properties that light, weather and the camera read. The day cycle is an animation of those same properties, and cars follow offset-path routes on a schedule that keeps crossing traffic apart.

Motion

If your system asks for reduced motion, the city starts paused and the camera cuts instead of flying. The Motion control pauses everything at any time.
